# Лабораторная работа №3 (Lab3_OP)

**Тема:** Разработка консольного приложения на C# с использованием математических функций и алгоритмов сортировки.

## Задание
Программа представляет собой интерактивное меню со следующими функциями:
1. Вычисление математической функции и игра «Угадай ответ» (даётся 3 попытки).
2. Вывод информации об авторе.
3. Генерация случайного массива, его сортировка двумя методами (пузырьком и перемешиванием) и сравнение времени выполнения.

## Как запустить
1. Убедитесь, что у вас установлен [.NET SDK](https://dotnet.microsoft.com/download).
2. Откройте терминал в папке с проектом.
3. Выполните команду:
   ```bash
   dotnet run
